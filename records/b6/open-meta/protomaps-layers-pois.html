Basemap Layers ​

The Protomaps basemap is built on OpenStreetMap and Natural Earth data. It does not include all data and tags from OSM; instead it is designed to strike a balance between tile size and completeness, for use as a general-purpose context map.

The organization of layers and tags is derived from the open source Tilezen project. The scope of contents and choice of data inclusion at certain zoom levels is intended to mirror the reference implementations of Tilezen styles such as Bubble Wrap.

The current version is Version 4.

Ranking ​

Points of interest are sourced from OpenStreetMap, and the wikidata tag is joined with the QRank dataset to determine their prominence. The determined QRank is then used to move prominent POIs to lower zoom levels.

For example, the station Alexanderplatz has Wikidata ID Q698497 and a QRank of 37850. A neighboring station, Jannowitzbrücke has Wikidata ID Q1647893 and a QRank of 11176. Alexanderplatz station thus appears at a lower zoom level than other stations.

To view or modify the mapping from QRank thresholds to zoom levels, see Pois.java.

Shields ​

The network and shield_text are designed for displaying localized highway shields. The values are derived from the OpenStreetMap ref tag, and a spatial join with administrative boundaries.

Example network values:

ValueSpriteDescription
US:USUnited States Numbered Highway System
US:IUnited States Interstate Highway System
NL:S-roadDutch S-road network
                                                                                 |
                                                                                  |

For example, an OpenStreetMap way with the tag ref=S100 where the way is contained within the Netherlands polygon as defined by ideditor.codes will gain the tags network=NL:S-road, shield_text=S100.

transit ​

Lines representing scheduled passenger services suitable for rendering on the map, even at lower zoom levels. For physical infrastructure, like highways and railways, see the roads layer.
