## 3. Every house in Montana

In the data, "every house in Montana" is a definition, not a file. The 2020 census counts 514,803 housing units. The statewide address-point list checked here, the Montana State Library (MSL) Structures and Addresses Framework, has 674,715 points, and 493,975 of them carry a residence code. The state ratio is 0.960, but residence-coded county ratios run from 0.477 to 1.356, so the definition chosen decides which counties look short. No source checked is verified to list every house.

- 24 counties are below 0.9 (verified). The verified facts give 18 counties from 0.9 to 1.1 and 14 above 1.1. The W6 working file analysis-summary.json gives 19 and 13. Both total 56, so one county near the 1.1 line is classed differently. Not reconciled.

- Each of the three lowest counties has a load dated 2023 or later (Glacier 2023-01-19, Roosevelt 2026-04-09, Big Horn 2026-07-31). - Missoula (0.748) and Silver Bow (0.635) are also below 0.9 in the working file. Both are among the five counties that maintain their own parcel data ("County maintenance of parcel data", verified). The evidence does not link the two.

**Recommended definition** (for the owner and counsel to accept; section 09 decides): a house is an MSL framework point with State MT, a County among the 56 Montana names, and Place_Type "residence" or "Residential". Position comes from the shapefile geometry (NAD83(2011) / Montana, metres), because the DBF Latitude and Longitude columns are 0.0 in every record ([montana-addresses.json](validation-evidence/montana-addresses.json), "Latitude and Longitude columns are zero"). No owner field is read: no field name in the 51-field table contains "OWN" ([hosting-and-architecture.json](validation-evidence/hosting-and-architecture.json), "Owner names in the structures file", verified). ParcelID stays out of published data, because it would link a published point to the owner fields in the parcel file; W9 raises this as an open question. The parcel file is not the base table: it is land-based, has no situs line on 400,210 records (43.5%, derived), and holds owner fields.

**Correction.** The MSL metadata does carry use-constraint text, although neither file gives a licence grant. The parcel use-constraint element quotes MCA 2-6-1017 and includes "for no other purpose"; the parcel liability field quotes MCA 2-6-109. The structures element carries a disclaimer with the same clause. The downloaded XML shows this (parcel metadata line 118; structures metadata line 310). W10's review says the opposite (review corrections, item 4, [evaluation-and-wording.json](validation-evidence/evaluation-and-wording.json)), and the downloaded XML contradicts it.
